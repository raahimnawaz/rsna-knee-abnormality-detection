# lingua is pinned EXACTLY and deliberately.
#
# sample_for_labeling.py stratifies by the language column in data/lang_detected.csv, which
# lingua produces. A different lingua release reclassifies some reports, which changes the
# per-language allocation, which changes the shuffle, which renumbers item_id -- and
# labeling/model_labels.csv joins on item_id alone. The 86 hand labels (including all 30
# blind gold studies) would then silently describe the wrong reports, with no error raised.
#
# Do not relax this pin without running:  python labeling/rekey_labels.py --check
lingua-language-detector==2.2.0

# Not determinism-critical; sampling reproducibility rests on numpy's RandomState/Generator
# streams, which are version-stable for a fixed seed.

# Data access only. New-style KGAT_ token at ~/.kaggle/access_token; kaggle.json is dead.
kaggle>=2.2

# The fusion head (PLAN.md 3.3) trains on the Mac Studio against cached DINOv2 embeddings --
# ~2.4 GB, not 570 GB -- so torch is a local dependency, not a Kaggle-only one.
#
# DO NOT CONTAINERISE THE TRAINING. Docker Desktop on macOS runs containers inside a Linux VM
# with no Metal passthrough; there is no Apple-silicon equivalent of `--gpus`. A dockerised run
# on the Studio trains on CPU, which throws away the entire reason for using it. torch MPS
# requires native macOS execution. Reproducibility here comes from these pins plus the
# preprocess fingerprint recorded in the cache manifest (pipeline/preprocess.py), not an image.
#
# pydicom/timm/dicomsdl are deliberately absent: those run only in the Kaggle notebooks, where
# the images live. Anything the SUBMISSION notebook needs must be preinstalled on the Kaggle
# image or shipped as a wheel in an attached Dataset -- inference has no internet.
